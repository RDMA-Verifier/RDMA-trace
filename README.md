# RDMA_SC Trace Explorer

[Open the interactive explorer](https://rdma-verifier.github.io/RDMA-trace/).

Explore executions of small RDMA programs with sequentially consistent CPUs,
reorder events, inspect memory-ordering relations, and enumerate allowed outcomes.

This repository contains the generated website. Updates are published automatically
from the private source repository. GitHub Pages serves the `main` branch from its
root directory.
