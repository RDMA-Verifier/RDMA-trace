The margin numbers each thread's statements. An event tag such as 2a is the first event of statement 2; a put or get also has a second event, 2b.

Updated elsewhere.

Syntax
node 1 { x = 0; a = 0 }
Locations of node 1 and their initial values. Undeclared locations start at 0 on the node that first uses them.
thread T1 @ 1 { … }
A thread running on node 1.
x := e
Local assignment. e uses numbers, local locations and + - *.
x := y^2
Get: the NIC reads y on node 2 and writes local x.
y^2 := x · y^2 := 1
Put: the NIC reads local x (or a constant) and writes y on node 2.
poll(2)
Wait until the oldest unpolled remote operation towards node 2 completes.
rfence(2)
Later remote operations towards node 2 wait for the earlier ones.
assume(x = 1)
A local read that must see 1. assume(x != 1) must not.
a := CAS(x, 0, 1)
Compare-and-swap on local x; a gets the old value.

Separate commands with ; or new lines. Comments start with //. Paper notation z² works too. Choice and loops are not supported yet.
